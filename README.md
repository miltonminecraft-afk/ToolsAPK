# ToolsAPK

Broncode voor de Tools-app en GitHub Pages.

- Landing: `index.html`
- Webtools: `tools/`
- Android/Capacitor: `android/`
- HIO scanner: native Android CameraX + ML Kit
- Assistent: lokaal/offline model. Web gebruikt lokaal gebundelde wllama/WASM; Android gebruikt een prebuilt llama.cpp AAR.
- Met internet kan de Assistent actuele informatie op het hele web zoeken. Bij KPN-vragen krijgen KPN.nl en KPN Community extra prioriteit.
